# Lavender Ember

A soft, creamy light theme for the Claude app: milky lavender backgrounds, creamy off-white panels, burnt-orange buttons and links, and deep burgundy-plum text with burgundy touches.

## Install

In a Claude Code session running on your computer, type:

```
/plugin install lavender-ember --marketplace alenamariec-web/lavender-ember
```

Answer `y` to add the marketplace, then pick a scope. Start a new session and the theme appears.

## Change the shades

Every color is in `hooks/palette.ts`, with a comment saying what it colors.
